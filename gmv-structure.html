第一部分 · 核心结论

  • 1. 你是"CSS 单腿"结构：CSS/比价占个人 GMV 96.2%，其余 6 类加起来不到 4%。
  • 2. 集中度极高：Top5 占 95.4%，Booncy 一家 57.6%；单点波动直接决定月度业绩。
  • 3. 大盘最大的类型缺口是 Cashback 与 Coupon/Deals：大盘分别 8.8% / 6.6%，你只有 0.3% / 1.2%（差 -8.5pp / -5.4pp）。
  • 4. 大盘最大的国家缺口是法国：大盘 FR 29.7%，你只有 8.5%（差 -21.2 个百分点），是单项最大差距。
  • 5. 你的优势市场是 DE / SE / NL：DE 41.9%（大盘 26.8%，+15.1pp）、SE 23.5%（大盘 9.9%，+13.6pp）、NL 13.9%（大盘 10%，+3.9pp）。
  • 6. TD 是结构性短板：13.7 万点击只出 19 单（CR 0.014%），而 TD 的 CSS 品类本身能出单（你的 CSS 3 单 / 5 千点击；Lexit 的 CSS 202 单）。
  • 7. 战略层几乎空白：Content/评测 0.5%、KOL/KOC 0%，长期新客与内容资产没有承接。
  • 8. 最值得争取的增量：① FR 的 Coupon/Deals；② DE 的 Cashback；③ TD 侧清理 Sub Network/Content 垃圾点击、把预算换到 CSS 与 Media Buying。

第六部分 · 数据限制与待验证假设

能支持的结论

  • 你的类型结构（CSS 96.2%）与集中度（Top5 95.4%）；
  • 你与 Lexit / 未分配组 / 大盘在类型与国家上的占比差距；
  • TD 侧点击与订单的悬殊（CR 0.014%）；
  • 各类型的有效伙伴数与人均产出。

只能作为假设的判断

  • Coupon/Cashback 的"潜在增量"是按占比差推算的方向，不是已验证的 GMV；
  • FR 的 $53k 来自未分配组，不代表你能复制同样产出；
  • TD 单期数据的绝对规模不能与 Impact 九个月直接相加比较。

仍需补充的数据

  • 佣金 / 结算成本（按类型、按国家）—— 没有它无法算 ROI 与真实净增；
  • 点击 / Sessions（Impact 侧）—— 目前只有订单，没有分母；
  • TD 按月的导出—— 现在只有单期，看不到趋势；
  • 第二个团队的组别定义—— 数据里只有 Charise 与 Lexit。
最影响判断的一项：佣金成本。没有它，"增量"可能只是"用更高佣金买来的收入"，并不等于利润增长。
